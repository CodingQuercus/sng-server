# Sketch'N'Guess — Server

Node.js + Socket.io server for Sketch'N'Guess.

**Client repository: [sketch-n-guess](https://github.com/CodingQuercus/sng-app)**

## To get started

1. Install dependencies
```bash
   npm install
```

2. Create a `.env` file:
PORT=3002

3. Start the server
```bash
   node server.js
```
