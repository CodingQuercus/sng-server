# Sketch'N'Guess — Server

Node.js + Socket.io server for Sketch'N'Guess.

Originally developed as a group project during the course *Prototyputveckling för mobila applikationer (5TF036)* at Umeå University (Autumn 2024). The codebase has since been refactored and cleaned up for portfolio purposes.

**Client repository: [sketch-n-guess](https://github.com/CodingQuercus/sng-app)**

## To get started

1. Install dependencies
```bash
   npm install
```

2. Create a `.env` file:
```
PORT=3002`
``

3. Start the server
```bash
   node server.js
```
